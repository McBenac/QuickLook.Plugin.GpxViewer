# QuickLook.Plugin.GpxViewer

Preview GPX tracks on Windows without opening a map app: select a `.gpx` file in Explorer, press
<kbd>Space</kbd>, and see where the track goes.

This is a plugin for [QuickLook](https://github.com/QL-Win/QuickLook), the free app that brings macOS-style
Quick Look to Windows: pressing <kbd>Space</kbd> on a file in Explorer shows a preview of it. Without the
plugin, QuickLook shows a `.gpx` file as XML text. With it, the track is drawn on a map, with its date,
distance and duration.

## What it shows

- Tracks (`trk`) as lines, each segment in its own colour, with the start (green) and end (red) marked
  and a dot for every recorded point (for tracks of up to 20,000 points). Click a dot for its time,
  coordinates and elevation.
- Routes (`rte`) as dashed lines and waypoints (`wpt`) as pins.
- A summary box: name, date and time of the first and last point, number of points, distance, duration
  and what the file contains.
- An elevation profile along the bottom when the track has elevation (`<ele>`).
- Three backgrounds, switched at the top right: **Map** (OpenStreetMap, Humanitarian style),
  **Satellite** (Esri World Imagery) and **No map** (the track on a plain grid). The choice is
  remembered.

GPX 1.0 and 1.1 are supported. A file that is not valid XML shows an error page with the parser's message.

## Privacy

In **Map** and **Satellite** mode the map tiles are downloaded from
[OpenStreetMap France](https://www.openstreetmap.fr/) (`*.tile.openstreetmap.fr`) and
[Esri](https://www.esri.com/) (`server.arcgisonline.com`). Which tiles are requested reveals roughly
where the track is, and the servers see your IP address. Nothing else leaves your computer: the file is
read locally and is never uploaded.

**No map** downloads nothing. Choose it once and it stays the default for the next previews.

## Install

**Prerequisites:** [QuickLook 4.x](https://github.com/QL-Win/QuickLook/releases/latest) — install it first; the plugin
is installed through QuickLook itself. It also needs the Microsoft Edge WebView2 Runtime, which Windows 10 and 11
already have.

1. Download `QuickLook.Plugin.GpxViewer.qlplugin` from [Releases](../../releases).
2. Select it in Explorer, press <kbd>Space</kbd> and click **Click here to install this plugin.**
3. Click **Restart now...** when the installation is done.

## Controls

- Drag to move the map, mouse wheel to zoom.
- <kbd>Space</kbd> or <kbd>Esc</kbd> closes the preview, and the arrow keys move to the next file, as usual in
  QuickLook.

## Troubleshooting

Each preview adds one line to `%LOCALAPPDATA%\GpxViewer\log.txt` with the file, the number of points and
the distance, how long it took, or the error.

## Building

The plugin is a .NET Framework 4.6.2 class library (WPF, WebView2) and builds on Windows:

```
git clone <this repository>
pwsh scripts/get-quicklook-common.ps1
dotnet build src/QuickLook.Plugin.GpxViewer.csproj -c Release
pwsh scripts/pack.ps1
```

`get-quicklook-common.ps1` fetches `QuickLook.Common` from the QuickLook release named in `quicklook-version.txt`,
so the plugin is built against the same library QuickLook ships. GitHub Actions does the same on every pull
request, checks the file detection against the test files and uploads the `.qlplugin`. A monthly workflow
opens an issue when QuickLook or Leaflet has a newer version than the one used here.

The web viewer in `viewer/` can be opened in any browser through a local web server, for example
`viewer/index.html?src=../tests/fixtures/track-time-ele.gpx`. `tests/viewer-test.cjs` checks it in Chromium
with [Playwright](https://playwright.dev/) against the expected values in `tests/fixtures/expected.json`.
The test files are synthetic and generated by `tools/make-fixtures.py`.
